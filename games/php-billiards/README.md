# PHP Billiards

PHP Billiards is a single-player pool practice table. PHP owns deterministic fixed-step ball physics while a game-owned WebGL2 renderer draws the isolated table. The application runs directly from its PHAR and has no Tiled, world-composition, Doom, or WAD dependency.

Aim and set power, top/back spin, and side spin while the balls are still. Drag the table to orbit, use the mouse wheel to zoom, and press **Shoot** or <kbd>Space</kbd>. After a scratch, move over the cloth and click or tap the cue-ball preview to place it. **Reset shot** restores the complete pre-shot state; **Rack** starts over.
