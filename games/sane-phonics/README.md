# Sane-Phonics

The extracted platformer demo and reusable gameplay systems for [Phonics](../../README.md). Install `@seanmorris/sane-phonics` alongside `@seanmorris/phonics`, or `seanmorris/sane-phonics` through Composer. The PHP namespace is `SanePhonics\`; this package supplies the old gameplay `PhpWasmEngine\` aliases until Phonics 1.0.

`phonics.json#game` plays the complete demo. `worlds/demo.world` includes the startup cards, title and menus. Other package-owned worlds select every existing course. The world properties `sane.scene`, `sane.profile`, and `sane.intro` configure this game. Browser scene/profile controls and legacy `bootEngine` calls remain supported by the demo host. Menus, level changes, vehicles, platformer tuning, rumble, text/dialog, phpinfo, camera behavior, outlines and streaming retain their existing behavior.

`phonics.json#platformer` independently registers movement and the `SanePhonics.Player` factory; `#player` exports that factory for Tiled. The module builds terrain from the session start map. Gameplay components and systems also remain individually available through PHP autoloading, without requiring demo startup. The game shares the session registry and scheduler with imported modules, spawns their Tiled factories, and retires those entities when their maps leave the level. Browser controls are optional; a host can provide only a canvas. The complete API and previous tuning documentation are in [gameplay.md](docs/gameplay.md); paths there are relative to this package unless explicitly framework paths. See also [loops](docs/loops.md), [menus](docs/menus.md), and [startup](docs/startup.md).

The framework owns shared fonts, controller glyphs and generic shaders. This package owns course maps, gameplay art and water shaders. Development assets are generated by `examples/generate-assets.php`. The root commands aggregate this package's PHP and browser suites. Production manifests and archives exclude the generators, tests and scratch files.

Open `worlds/demo.tiled-project` in Tiled 1.12 or later after installing the repository dependencies with `npm install`. Enable the project extension when prompted, then open a course world. The project includes the portable custom classes, map/assets folders, and a relative extension path. Worlds name their modules in native Tiled lists; maps select `@sane/demo-map`, and the streaming world selects `@sane/spatial-maps`. Player start points use a nested `SpawnPoint` component, also available as `templates/spawn.tx`. Existing terrain and feature loaders remain game-owned; importing a spritesheet does not activate gameplay systems. Legacy `Player` points and the standalone player factory remain supported.

The project defines 34 concrete `SanePhonics.Entity.*` presets and their nested settings classes. Drag a `.tj` file from the `templates` folder onto an object layer to place rings, each monitor reward, enemies, vehicles, platforms, bridges, water features, rails, springs, or text. Rings work as both painted tiles and independent objects. Templates retain their source tileset, and instance overrides stay nested under the relevant setting (`Monitor`, `RingMonitorEffect`, `PlatformPath`, and so on).

Choose map-local targets after placing linked features: `GrapplePoint.tiedTo`, `BossRegion.boss`, `WaterSwitch.water`/`setPoint`, and `PlatformPath.path` or `ridePath`; connect `PathNode.next` to continue or loop a route. Zero ends a path, and an unset route leaves a platform stationary. A collision layer of `-1` keeps the existing inherited/default plane. For springs and gravity switches, zero length uses the object width (at least 32), and a zero normal vector derives its direction from object rotation. Enemy/platform timing retains the existing 60 Hz reference-frame units.

`authoring.mjs` is the schema source; `node examples/generate-presets.mjs` regenerates the project, portable class catalog, and templates. Course generators preserve nested values. `SanePhonics\Tiled\Authoring` resolves these presets before the existing game-owned loaders construct their ECS components; legacy flat maps remain supported. These settings classes do not register new global framework systems.

See [Authoring courses in Tiled](docs/authoring.md) for the complete template catalog, nested settings, object links, and save/validate/build workflow.
