# Gameplay guide

Choose a course to try a feature, then follow the chapter for the system you want to reuse or change. The controls below apply across the demo; vehicle chapters include their additional controls.

## Play the demo

Press the **Play Sane-Phonics** poster on the [Sane-Phonics page](index.md). The demo shows download progress, intro cards, a scrolling title with a **Press Start / Enter** prompt, and a main menu. Choose **Play** to load the selected level. **Level**, **Movement**, and **Settings** configure the run before play.

Press **P**, **Escape**, or **Start / Options** during play to open the pause menu. **Level** selects Platformer, Moving platforms, Bendable bridges & rails, Light dash, Grapple ropes, Skateboard course, Tornado flight course, EggWalker proving ground, Water regions, Underwater rail, Surface skim rail, Rising water loop, Gravity switches & springs, Curved ceiling springs, CrabMeat badniks, Grinding rail, Streaming world, Loop-de-loop, Breakable blocks, Infinite map, or Isometric map. Grinding rail appears only in the pause menu's list; the main menu offers the others. **Movement** selects runner, glider, or flyer. Level changes keep the running engine, clock, player object, and menu settings. Movement changes apply to the current player in place. **Main menu** retains the level for **Resume game**.

The bottom-right speaker and fullscreen buttons share their state with the pause menu. Mute persists across reloads when browser storage is available. Fullscreen expands only the game frame and its corner controls; use the corner button or Escape to return. Page text stays outside fullscreen.

Controls: arrows/WASD to move, Space/Z to jump, Down to crouch, tap Jump or hold X while crouching and release Down to spindash, hold X through a jump landing to drop dash, hold C near an airborne ring trail to light-dash, jump again to glide or fly, Up/Down to climb, and R to reset position. Choose **Level** or **Movement** in the pause menu to switch scenes or profiles during play. In **Streaming world**, arrows/WASD pan, R returns to the start, and X retries failed downloads. The status line lists loaded maps; the Network panel shows maps arriving as you approach. Demo art is generated by examples/generate-assets.php.

**Shift+R** reloads the current level, restoring rings, enemies, monitors, breakable blocks, and moving platforms. The pause menu has **Restart level**; on a controller, hold **B / Circle** and press **Back / Select**. Restart returns the player to spawn and resets the level timer and ring count while retaining score, movement profile, settings, and the running PHP session. R alone resets position without rebuilding the level.

Gamepads work in every scene. Click the canvas and press a gamepad button if the browser has not exposed the controller yet. The supported movement and ability buttons follow moving-boxes-2:

| Action | Gamepad | Keyboard |
| --- | --- | --- |
| Move, pan, climb | Left stick or D-pad | Arrows / WASD |
| Jump; tap while crouching to add spindash charge | A / Cross (south button) | Space / Z / Enter |
| Crouch; hold dash and release Down to launch | Down + B / Circle | Down + X / Shift / Ctrl |
| Charge drop dash during a jump | B / Circle (east button) | X / Left Shift / Ctrl |
| Light-dash along rings while airborne | Hold X / Square (west button, 2) | Hold C |
| Pause / resume | Start / Options | P / Escape |
| Reset position (demo shortcut) | Back / Select / Share | R |
| Restart level and restore its objects | Hold B / Circle + Back / Select | Shift + R |
| Retry world downloads | B / Circle | X |
| Roll into breakable blocks | Down while moving | Down / S while moving |
| Fire-shield air thrust | LB / RB (L1 / R1) | Q / E |

In **Breakable blocks**, walking stops against a block and jumping can land on top. Gain speed and hold Down to roll through it, breaking it into a grid of particles without losing momentum. At rest, hold Down to crouch; after 0.75 seconds the camera looks lower. Tap Jump to add a discrete charge or hold X or B / Circle to build charge continuously, then release Down to launch a spindash. Untapped charge slowly decays, and charging recenters the camera. Shift+R or **Restart level** restores all three blocks. Their nested `BreakableBlock.columns` and `BreakableBlock.rows` fields in `examples/assets/breakables.tmj` set the grids to 4×3, 2×8, and 8×2. Tiled tile-object sizes set their world dimensions.

## Authoring names and runtime components

Open the project's [Tiled authoring guide](authoring.md) for the concrete presets, placement templates,
and nested settings. Current objects use `SanePhonics.Entity.*` classes. The sections below also
name the legacy loader classes and PHP components; those names remain useful for scripted creation
and importing older maps. A field such as `GrapplePoint.tiedTo` means `tiedTo` inside the
`GrapplePoint` settings group, not a flat property with a dot in its name. Legacy flat fields remain
supported on legacy objects. Sprite-animation tile annotations retain their existing names.
